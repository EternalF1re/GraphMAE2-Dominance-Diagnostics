# Recent Baseline Integration Core

`sota_baseline_extension.py` is a public reproduction adapter derived from the frozen formal implementation; it is **not a one-command replay of the private historical schedule**. The source snapshot SHA-256 was `c8701ec4f1148fb1bc8355f6ed8e9b99fe8865e37fa0c39a4117eb3caec5dc72`. The Aligned-MTL and FAMO calculation function bodies are copied from that snapshot; the historical CLI, source gate and private-schedule coupling were removed. `bind_runner(compatible_runner)` is the public injection point. This file does not contain datasets, checkpoints, frozen root schedules or the full training runner.

The adapter's `shared_encoder_parameters` selects the ordered trainable GNN encoder parameter set. Aligned-MTL uses raw reconstruction and latent losses, keeps branch-only gradients, and transforms shared parameter gradients with a symmetric eigendecomposition using `torch.linalg.eigh`; its direct R-hat is explicitly **pre-transformation representation-level**. FAMO uses the same raw losses, updates the effective task-weighting state after a same-batch post-model-step forward replay, restores RNG state, and logs the actual applied relative multiplier. Both use the GraphMAE2 full-model gradient clipping constant supplied by the compatible runner. `direct_rhat.py` delegates to the existing shared-target gradient measurement and accepts the weights applied at the completed update.

The included Nash function is the **attempted original local integration**, not a completed comparator and not a post-hoc solver revision. The preregistered Nash-MTL comparison did not complete under the adopted integration configuration and is not included as a completed comparator. The official previous-alpha fallback was not retained under the frozen preregistered behavior, and the local pre-solve guard existed. The observed failure must not be interpreted as general Nash-MTL instability.

For analysis-level reproduction, use the released processed records and `tables/` scripts. Binding this adapter to an independently supplied compatible training runner requires the user to supply their own data, schedule and evaluation assets; the public package makes no claim of exact historical replay.
